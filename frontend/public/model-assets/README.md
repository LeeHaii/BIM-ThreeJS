# Runtime model fixtures

- `small.*.frag` is generated from That Open's MIT-licensed `small.ifc` fixture.
- `box.glb` is Khronos' glTF Box sample, © 2017 Cesium, licensed CC BY 4.0.

These files exercise real binary loading and disposal. Replace them through the
admin asset workflow before production acceptance with a representative project
IFC and environment.
